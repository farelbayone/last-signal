# LAST SIGNAL

A small top-down survival puzzle made with vanilla HTML, CSS, and JavaScript.

## Play locally
Open `index.html` in a modern browser.

## Publish on GitHub Pages
1. Upload `index.html` and this `README.md` to the root of your public repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/(root)`, then save.

## Controls
- WASD / arrow keys: move
- Shift: sprint (makes more noise)
- E: interact with nearby objects
- Esc: pause
- Mobile: use the on-screen directional pad; tap the game area to interact

## Objective
Recover the access card in the east storage area, restore the relay panel in the southwest, then reach the exit in the northeast. Avoid the Watcher and keep your footsteps quiet.

No build tools or backend required.
